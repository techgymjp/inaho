# 水田365日

福島・会津の山あいにある田んぼの一年を、**1日＝1分**で見守る 3D の風景シミュレーションです。
稲刈りの時期だけ、田んぼを**スワイプして稲を刈り取り**ます。

## あそびかた

- ゲームは「今日の日付」から始まります（実際のカレンダーと同じ日から一年が進みます）。続きは「つづきから」で再開できます。

- 田んぼの一年が 1日およそ1分で進みます。日が出ている間はゆっくり（×0.5）、夜は速く（×2）。右上の「×1」で ×10 / ×60 / ×600 に早送りできます。
- 📖「いまの田んぼ」（左下）は季節の説明で読むだけ。👆「農作業イベント」（金色の枠）が出たら、あなたの作業です。
- 景色は畦道からの望遠で、一年中同じアングルです。ドラッグで見回し、「視点」で 空から・里山・水路 にも切り替えられます。
- **9月22日〜10月20日は稲刈り**。田んぼを指（マウス）でなぞると刈り取れます。
  - いつもの景色のまま、田んぼの稲の上からなぞると刈り取れます（田んぼの外からのドラッグは見回し）。
  - 9月28日〜10月8日に刈ると一等米。刈り遅れた稲は倒れてしまいます。
  - 刈った稲は、はざ掛けで干されます。収穫量（kg・俵・ごはん何杯分）が記録されます。
- 遠くの線路をローカル線が走り、カタンコトンと音がします。
- 夕方（4〜9月は18時、ほかは17時）には「家路」（ドヴォルザーク「新世界より」）のチャイムがワンフレーズ鳴ります。
- 日本語 / English 対応（メニューで切り替え。初回はブラウザの言語に合わせます）。
- 進み具合はブラウザに自動保存されます。

## 農作業イベント

一年を通して、どれも「いつもの景色のまま田んぼをなぞる」操作で農作業をします。イベントが始まると時間は等速に戻り、出来ばえがその年の収量・等級に響きます（結果画面に内訳）。

| 時期 | 作業 | 操作と影響 |
| --- | --- | --- |
| 4/15〜4/26 | 田起こし | なぞって耕す（耕した割合で収量 ×0.90〜1.00） |
| 4/28〜5/11 | 代かき | 水を張った田んぼをなぞって泥のかたまりを平らに（×0.94〜1.00） |
| 5/15〜5/23 | 田植え | なぞって苗を植える。植え残しは遅れて植えられ収量−15% |
| 6/1〜6/24 | 除草 | 次々生える雑草（ヒエ）をなぞって抜く。残ると最大−12% |
| 8/5〜8/25 | カメムシ防除 | 飛び回るカメムシをなぞって捕まえる。逃すと等級が下がる |
| 9/8〜稲刈り | スズメ追い | 稲をついばむスズメの群れをなぞって追い払う。被害は収量から差し引き |
| 9/22〜10/20 | 稲刈り | なぞって刈り取る。9/28〜10/8 で一等米 |
| 11/25〜12/7 | 畦の補修（冬） | 畦に開くモグラ穴や崩れをなぞってふさぐ。残すと翌年、水がもれて収量−最大6% |
| 1/8〜2/25 | ハウスの雪下ろし（冬） | 雪の日に育苗ハウスの屋根に雪が積もる。屋根をなぞって下ろす。つぶれると買い苗になり収量−10% |
| 2/28〜3/20 | 融雪剤まき（冬） | 雪の田んぼをなぞって黒い融雪剤をまく。まいた所から早く雪がとけ、収量 ×0.98〜1.03 |

農作業イベントが始まると時間が止まり、「やること・結果への影響・期間」のカードが出ます。「はじめる」で再開。作業ごとに効果音が違います（ザクッ、チャプッ、プスッ、ブチッ、パシッ、ペタッ、サラサラ…）。

冬の田んぼには猪苗代湖から白鳥が落ち穂をついばみに来ます（12月中旬〜3月上旬）。

## 再現しているもの

- **農作業の暦**：会津地方の一般的な時期をもとに、種もみ準備・育苗・田起こし・代かき・田植え・除草・中干し・追肥/防除・出穂・登熟・落水・稲刈り・乾燥調製・秋起こし・冬支度。
- **山あいの日照**：まわりの山の稜線を方位ごとに計算。空は日の出とともに明るくなり、田んぼは太陽が稜線を越えて実際に日が差したときに明るくなる（夏至で約25分、冬至で約40分遅れる）。盆地が山かげの間は、高い斜面だけが朝日・夕日に染まる。
- **夜のあかり**：防犯灯、家の窓、古民家の障子、寺の石灯籠、電車の窓。
- **太陽と月**：福島県（北緯37.5°）の太陽の高さと方位を天文計算で求め、季節ごとの日の出・日の入りを再現。月の満ち欠けも。
- **季節**：雪どけ、山の雪線、新緑、紅葉、桜（一本桜）、雪景色。
- **天気**：月ごとの傾向（梅雨・秋晴れ・冬の雪）から日ごとに変わる晴れ・くもり・雨・雪、春と秋の朝霧。
- **いきもの・音**：蛙、ミンミンゼミ・アブラゼミ・ヒグラシ（夏）、鈴虫（秋の夜）、ウグイス（春）、小鳥、蛍（6〜7月の夜）、赤とんぼ（9〜10月）。音はすべて WebAudio で合成。
- **季節の花**：桜並木と菜の花（春）、紫陽花（初夏）、ひまわり畑（夏）、コスモスと紅葉（秋）。
- **里の建物**：茅葺きの古民家、白壁の納屋（土蔵造り）、板張りの小屋、屋敷林の杉、集落と寺（本堂・鐘楼・石灯籠・杉木立）、柿の木（秋に実る）。
- **遠景の山の四季**：冬は雪山、春は残雪、夏は緑、秋は紅葉と初冠雪。
- 遠景の山は猪苗代から見た磐梯山の姿を参考にしています。

## 動かし方

ビルド不要の静的サイトです。ES Modules を使うので、ローカルでは簡単なサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 公開（GitHub Pages）

**Settings → Pages** で `main` ブランチ（/ root）から公開しています。`main` に push すると自動で更新されます。

公開URL：https://techgymjp.github.io/inaho/

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html`, `css/style.css` | 画面・UI |
| `js/main.js` | 時間の進行、カメラ、刈り取り操作、保存、UI |
| `js/calendar.js` | 暦・農作業・太陽位置・天気・稲の生長 |
| `js/landscape.js` | 空・雲・山・森・農家・桜・電柱・鉄道 |
| `js/field.js` | 田んぼ（田面・畦・水鏡・稲・はざ掛け・刈り取り判定） |
| `js/effects.js` | 雨・雪・蛍・赤とんぼ・わらくず |
| `js/audio.js` | 環境音 |
| `js/toon.js` | イラスト調（セルシェーディング）の設定 |
| `js/textures.js` | 草・茅・板・トタン・障子などの手描き風テクスチャ |
| `js/flowers.js` | 季節の花と紅葉 |
| `js/i18n.js` | 日本語 / English |
| `js/farmwork.js` | 農作業イベント |
| `lib/` | three.js r170（MIT License）を同梱 |

画質は「メニュー → 画質」で 高 / 軽量 を切り替えられます（スマートフォンは軽量が既定）。
