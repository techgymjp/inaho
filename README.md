# 水田365日

福島・会津の山あいにある田んぼの一年を、**1日＝1分**で見守る 3D の風景シミュレーションです。
稲刈りの時期だけ、田んぼを**スワイプして稲を刈り取り**ます。

## あそびかた

- 田んぼの一年が 1日＝1分 で進みます（1年で約6時間）。右上の「×1」で ×10 / ×60 / ×600 に早送りできます。
- ドラッグで見回し、「視点」で 畦道・空から・里山・水路 を切り替えます。
- **9月22日〜10月20日は稲刈り**。田んぼを指（マウス）でなぞると刈り取れます。
  - 9月28日〜10月8日に刈ると一等米。刈り遅れた稲は倒れてしまいます。
  - 刈った稲は、はざ掛けで干されます。収穫量（kg・俵・ごはん何杯分）が記録されます。
- 遠くの線路をローカル線が走ります。
- 進み具合はブラウザに自動保存されます。

## 再現しているもの

- **農作業の暦**：会津地方の一般的な時期をもとに、種もみ準備・育苗・田起こし・代かき・田植え・除草・中干し・追肥/防除・出穂・登熟・落水・稲刈り・乾燥調製・秋起こし・冬支度。
- **太陽と月**：福島県（北緯37.5°）の太陽の高さと方位を天文計算で求め、季節ごとの日の出・日の入りを再現。月の満ち欠けも。
- **季節**：雪どけ、山の雪線、新緑、紅葉、桜（一本桜）、雪景色。
- **天気**：月ごとの傾向（梅雨・秋晴れ・冬の雪）から日ごとに変わる晴れ・くもり・雨・雪、春と秋の朝霧。
- **いきもの・音**：蛙、蝉、鈴虫、鶯、小鳥、蛍（6〜7月の夜）、赤とんぼ（9〜10月）。音はすべて WebAudio で合成。
- 遠景の山は猪苗代から見た磐梯山の姿を参考にしています。

## 動かし方

ビルド不要の静的サイトです。ES Modules を使うので、ローカルでは簡単なサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 公開（GitHub Pages）

`main` に push すると `.github/workflows/pages.yml` が GitHub Pages にデプロイします。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html`, `css/style.css` | 画面・UI |
| `js/main.js` | 時間の進行、カメラ、刈り取り操作、保存、UI |
| `js/calendar.js` | 暦・農作業・太陽位置・天気・稲の生長 |
| `js/landscape.js` | 空・雲・山・森・農家・桜・電柱・鉄道 |
| `js/field.js` | 田んぼ（田面・畦・水鏡・稲・はざ掛け・刈り取り判定） |
| `js/effects.js` | 雨・雪・蛍・赤とんぼ・わらくず |
| `js/audio.js` | 環境音 |
| `js/toon.js` | イラスト調（セルシェーディング）の設定 |
| `lib/` | three.js r170（MIT License）を同梱 |

画質は「メニュー → 画質」で 高 / 軽量 を切り替えられます（スマートフォンは軽量が既定）。
